# Define the scenario

As we have defined the governance constraints, we continue with the overall scenario definition. The scenario definition is a first step to translate the plain language requirements into structured BTP infrastructure requirements. The result of this step is a first draft and will be further refeined in the following steps.

## 🛠️ Execute the scenario command

Execute the following command in the claude terminal:

```bash
/btp-iac.scenario
```

### 🔬 Look behind the curtains

The technical foundation of the step is the `btp-iac.scenario.md` skill located in the `.claude/commands` folder. The skill contains basic instructions for the agentic tooling to define the scenario.
