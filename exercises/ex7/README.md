# Define the tasks

In this exercise, we will take a look at the tasks that the agentic tooling has planned to do in order to generate the Terraform code. The tasks are based on the scenario and refinement of the different aspects from the previous steps.

## 🛠️ Execute the tasks command

Execute the following command in the claude terminal:

```bash
/btp-iac.tasks
```

### 🔬 Look behind the curtains

The technical foundation of the step is the `btp-iac.tasks.md` skill located in the `.claude/commands` folder. The skill contains the instructions for the agentic tooling to calculate and present the tasks that it plans to do in order to generate.

- Result + Check the created markdown file in the `specs` folder. Cross check what has happened in the `memory` folder.
